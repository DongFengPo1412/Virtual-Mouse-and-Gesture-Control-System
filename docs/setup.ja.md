<a id="operation"></a>

## 起動と操作

```powershell
python -m pip install -r requirements.txt
python main.py
```

ルートから起動します。初期操作は有効、カメラ0／640×480固定要求で、選択メニューはありません。スイッチは検出／表示、平滑度を上げると遅く、XY感度は活動域を縮めます。

人差し指で移動、親指とのピンチ保持で左・ドラッグ、離して解放します。右は移動条件を外して親指と中指です。3指を伸ばし小指を曲げて上下移動するとスクロールし、中心域で止まります。Q/Esc終了はなく主窓で閉じます。表示を消しても検出は止まりません。

<a id="lifecycle"></a>

## 停止・終了の既知問題

実際のカーソル・ボタン・ホイールを操作します。角のFAILSAFEは無効で、停止・終了で左が押されたままになる経路があります。実機試験では物理入力を使える状態とし、先にピンチを離して終了します。修正済みではありません。

撮像失敗、スレッド例外、掌尺度の退化、ワーカーのTk変数アクセスで清掃経路が中断し得ます。スイッチを検証済み全体緊急停止や入力隔離とは扱いません。

<a id="checks"></a>

## 検査と今後

Python4本を解析し、MouseControllerは生成していません。コンストラクタはデスクトップを読み、常駐入力スレッドを起動するためです。モック結果をカメラ・OS操作成功とはしません。

| 現象 | 確認 |
| :--- | :--- |
| solutionsがない | APIが非互換。必要なHandsインターフェースを提供する環境。 |
| 範囲・方向不適切 | 鏡像、実フレーム、固定640/480、余白、画面寸法。 |
| 右が動かない／連発 | 移動優先、人差し指、0.35と0.5 sの状態。 |
| 停止後も押下 | 既知の解放不足。物理入力で復帰し、終了処理を別途修正。 |
| FPSや感触が違う | ループ推定・固定180 Hz表示は性能保証ではありません。 |

解放・終了を先に検証し、追従誤差、姿勢、クリック・ドラッグ・スクロール、OSイベント時刻を評価します。
